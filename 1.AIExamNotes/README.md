# AI StudyMate 🤖📚

AI StudyMate is an AI-powered study assistant designed to help students understand and revise their study material more effectively.

## 🚀 Features

- 📄 Upload study material
- 🤖 Generate AI-powered summaries
- 📌 Generate important points
- 📖 Generate definitions
- ❓ Generate exam questions
- 🧠 Take quizzes
- 🃏 Create and review flashcards
- 📚 Save and manage study materials
- 📊 Track learning progress
- 🔐 User authentication
- 🔑 Google authentication
- 🌐 REST API integration

## 🎯 Purpose

The main purpose of AI StudyMate is to make studying easier by using AI to convert study material into useful revision resources such as summaries, important points, definitions, questions, quizzes and flashcards.
